隨機 ID 僅存在此裝置。若要在手機與電腦共用同一組持股，請在各裝置設定相同的 User ID。

  • 部署 HTTPS 後，將 APP_URL 設為 https://你的網域/app。
  • 執行 python setup_rich_menu.py 上傳底部選單（需 Channel Access Token）。
  • Rich Menu 各格會開啟不同錨點（首頁 / 持股 / 截圖 / 設定 / 說明）。
  • 截圖辨識需設定 ANTHROPIC_API_KEY 或 CLAUDE_CODE_OAUTH_TOKEN。
